# dsh-pixel-studio

在 DeepSeek Harness（DSH）里画像素画：会话页签里一个三栏编辑器，左工具、中画布、右调色板，铅笔、橡皮与直线 / 矩形 / 椭圆，连续缩放、图层、矩形选区、最多 256 色的调色板，作品存在本机，可导出 PNG 与调色板 JSON。

## 装法

三种都可以，装完刷新页面，会话页签行里会出现“像素画”。

```bash
# 1) 官方插件管理页 / 插件市场里搜索 @muxiuesd/dsh-pixel-studio
# 2) DSH CLI（npm）
dsh plugin --profile web add @muxiuesd/dsh-pixel-studio
# 3) 直接从 GitHub 仓库装（仓库根就是插件包）
dsh plugin --profile web add github:Muxiuesd/dsh-pixel
# 4) 本地开发
dsh plugin --profile web add /绝对路径/dsh-pixel
```

## 能做什么

- **画布**：尺寸 1–2048×2048；连续缩放 `0.125×…64×`，顶栏对数滑杆配合滚轮，滚轮以光标为锚点；`F` 适应窗口，顶栏「自适应开 / 关」决定窗口大小变化时是否重新适应画布；空格 / 中键拖动平移；`4×` 以上显示格线（可关）。2048×2048 也流畅：合成结果带缓存，棋盘格与网格只绘制可视区。
- **工具**：铅笔、橡皮、油漆桶（按合成后的颜色判断连通，视觉同色一次填满）、吸管；方形笔刷 `1–8` 像素。
- **直线 / 矩形 / 椭圆**（`L` / `R` / `O`）：拖拽出形状，松手后画布下方出现面板，`✓ 确认` 写入当前图层、`✕ 取消` 丢弃（`Enter` / `Esc` 同效）。预览框上有调整点——矩形与椭圆八个（四角优先）、直线两个端点——拖动它们改宽高或端点，拖框内整体移动；按住 `Shift` 约束成 45° 直线或正方形。矩形与椭圆各有一枚「是否填充」开关，决定确认时是否连内部一起填满，两者互不影响。预览跟着工具走：换工具、换颜色、换图层、换笔刷、开对话框、在画布外按下都会丢弃，不会误写入图片。
- **选区**（`M`）：拖出矩形选框；拖动框内只移框，`Shift + 拖动` 带像素一起走；镜像 / 填充 / 删除默认作用当前图层，「多层」或 `Alt` 作用全部可见层；方向键微调，`Ctrl+A` 全选，`Esc` 取消。在画布外按下、切换工具 / 颜色 / 图层、打开对话框都会直接打断选区，不残留选框，也不会沿边缘误画；被抬起的内容会放回原处。
- **图层**：最多 8 层，新建 / 复制 / 合并下行 / 上移 / 下移 / 删除 / 改名 / 显隐，全部可撤销。
- **调色板**：最多 256 色（前 36 个槽位与旧作品保持兼容，旧画不会错色）；色块放不下时出现细滚动条，放得下时不出现；内置 PICO-8 等预设板。
  - 改某个槽位的颜色**不会改动已经画好的像素**：旧颜色会先由一个空闲槽位接手并重映射像素。改色是草稿语义——点「完成」才写入，面板上并排显示「原色 / 新色」对比，切换色块或按 `取消` 即丢弃。
  - 取色：内置取色环（外圈色相、中间方块明暗，边角可吸附到纯色）+「取互补色」按钮，也可以调系统取色器或直接输 HEX / RGB。
  - **调色板 JSON**：「⇩ 导出」把当前调色板写成 `{ format, version, name, colors }` 的 JSON；「⇧ 导入」支持本插件导出的 `.json`，也容错读取 `.gpl` / `.pal` / 任意含 `#rrggbb` 的文本（带 BOM、`#rgb` 简写、`rgb(r,g,b)`、十进制色值都可以），可选「覆盖当前调色板」或「追加」，超出 256 色上限会提示未导入的数量；选到图片或二进制文件会给出明确提示。
- **作品**：新建时填名字和尺寸（1–2048），另有 11 个常用尺寸预设，可选「沿用当前调色板」；自动保存。
- **打开图片**：选一张 PNG / JPEG / GIF / WebP / BMP，自动缩到 2048 以内；配色可选自动提取（中位切分）/ 当前调色板 / PICO-8，也可以取消「使用图片自己的调色板」把颜色映射到现有调色板；可开 Floyd–Steinberg 抖动，导入前先看预览。
- **画布尺寸 / 裁剪**：`尺寸` 里改宽高（1–2048），9 宫格锚点决定裁掉哪边或从哪边扩边，扩边补透明，改完可以撤销。
- **导出**：首次导出选择保存位置（默认从当前会话目录开始），之后导出直接覆盖那个文件；`另存为` 随时换位置，并可挑 1×–16× 的导出倍率（会记住上次的选择）。导出的调色板 JSON 末尾不带多余换行。
- **与外壳相处**：像素画页签可见时自动收起聊天列的宽度拖拽手柄与下方的对话输入框，切走或关页签立即交还；顶栏「对话框隐藏 / 显示」可单独开关，切页不会影响其他页签。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `B` / `E` / `G` / `I` | 铅笔 / 橡皮 / 油漆桶 / 吸管 |
| `M` | 矩形选区 |
| `L` / `R` / `O` | 直线 / 矩形 / 椭圆 |
| `Enter` / `Esc`（画形状时） | 确认写入图层 / 取消形状 |
| `Ctrl/Cmd+A` | 全选选区 |
| `Esc` | 取消选区（浮动的内容回到原处） |
| `Delete` / `Backspace` | 删除选区内像素 |
| `Ctrl/Cmd+C` / `Ctrl/Cmd+X` / `Ctrl/Cmd+V` | 复制 / 剪切（内容留在画布上） / 粘贴 |
| `Shift + H` / `Shift + V` / `Shift + F` | 选区水平镜像 / 垂直镜像 / 填充 |
| 方向键（配合选区） | 微调选区 1 像素，`Shift` 为 10 像素 |
| `[` `]` | 笔刷变小 / 变大 |
| `H` | 格线开关 |
| `F` | 适应窗口 |
| `+` / `-` | 放大 / 缩小 |
| 空格 + 拖动、鼠标中键 | 平移画布 |
| `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z`（或 `Ctrl+Y`） | 撤销 / 重做 |
| `Ctrl/Cmd+S` | 保存 |
| `Ctrl/Cmd+Shift+S` | 另存为 PNG |

## 数据与能力

- 作品存在 `<profile 目录>/../pixel-studio/works.json`（默认 `~/.dsh/pixel-studio/works.json`），不上传、不联网。
- 插件只注册一个 Host 路由 `/dsh-pixel-studio`（同源 `fetch`），用于读写作品、写 PNG 与调色板 JSON 文件；不执行命令、不访问网络。
- 导出的 PNG 由插件自己编码（IHDR + zlib + IEND），不依赖任何图像库。
- 调色板超出 36 色时，第 37 个以后用 Unicode 私用区字符（U+E000 起）作为层内索引，每个像素仍然只占一个 UTF-16 单元。

## 环境

- DSH 0.2.x（Web / Desktop 均可），Node.js ≥ 20。
- 客户端用 `window.__ModuleLoader__` 加载，`react` 走宿主模块表，不打包 React。
